# 4.4 Wireframes

- **Login:** clinic name + username/password.
- **Appointments:** search by appointment number (Display details) + table + Register visit.
- **Register:** patient, address, phone, dentist, treatment, date, time slot.
- **Details:** all brief fields + bill link.
- **Bill:** treatment fee, consultation fee, total, print.
- **Help:** six numbered steps from the brief (login, register, display, bill, help itself, exit).
- **Exit:** left-menu sign out.
